# Custom Format Guide

Custom format functions give you the ability to create the output the way you want it, rather than trying to make a standard library function work.

## Format Function Specification / Expectation

Format functions are expected to have type `(file: TextIO, data: List[Segment], ...) -> None`. A type checker will enforce this through the registration decorator.

### file

`file` is an open file, either stdout or a text file. The function should write to this file, and not close it. The program will close it immediately after the function call.

### data

`data` is a list of Segment class objects. Each segment is a single clocked in time period. This list has been sorted by inTime. All timezones are converted to the output timezone specified, I suggest that you do not alter the timezones in the format function.

```python
@dataclass
class Segment:
    job: str # empty string if not specified
    inTime: datetime.datetime
    outTime: datetime.datetime
    description: str # empty string if not specified, can be multiple lines
    elapsed: datetime.timedelta # calculated outTime - inTime
```

### Other parameters

Your function can take in other parameters other than file and data. These parameters can either be values created by the program or further options specified in the macro output config. The function is very strict about name checking. You may use **kwargs, but this will bypass checking altogether. Using other parameters is not required. You should always try and set default values for all parameters so there is a default configuration for your output.

#### Program Parameters

Parameters generated by the program are values that may be useful to your specific output format. There are a couple things to note.

1. The user can not overwrite these params in the config, they are reserved for the program generated values.
2. If you use **kwargs, all program params will be provided.

The following program parameters are available to be used:

| Name | type | Description |
| :--- | :--- | :---        |
| **filter_start_date** | date \| None | The start date used to filter the segments, given by start_date on the command line or calulated through period mode. None if no filter was applied. |
| **filter_end_date** | date \| None | The end date used to filter the segments, given by end_date on the command line or calulated through period mode. None if no filter was applied. |

#### Output Config Parameters

You can choose to have variations on your format function by allowing the user to specify parameters in the macro output config. These will pass directly to the format function.


### Other specifications

- Return value: None, the return value is not checked by the program
- Errors raised by the function remain uncaught
- In order for the function to be used, it must be registered with the decorator @register_formatter("name") in fluxcard.output_registry. Names must be unique across the standard library and all your plugins. See the [setup instructions](#setup-instructions) below.
- Docstring: The `--list-formats` option will use the first line of the docstring as a description if provided.


## Setup instructions

1. Add the python file containing your function to your config file under `output_plugins`. This can be absolute path or relative to the config file.
```toml
output_plugins = ["filename.py"]
```
2. Define and register your function. In your python file, make sure to import the register formatter decorator. Set the name you want to use as the parameter of register_formatter.
```python
from fluxcard.output_registry import register_formatter
from fluxcard.segments import Segment

@register_formatter("custom_name")
def custom_function(file: TextIO, data: List[Segment]):
```
3. Check that your function has been properly registered when you run the program. 
    - Make sure that the program is grabbing your correct config file first.
    - The program will log that it has imported your module and that your format has been registered
    - You can use `--list-formats` to see if yours shows up.

4. Call your format function. Use your format function in the `-o / --output` flag on the command line or set a macro to use it as an output format.

## Example

Actual example from the standard library

```python

from typing import List, TextIO

from fluxcard.output_registry import register_formatter
from fluxcard.processors.formatters import timedelta_HH_mm_ss
from fluxcard.segments import Segment

@register_formatter("csv")
def output_csv(file: TextIO, data: List[Segment],job_column: bool = True):
    """Create a csv with the raw date, in time, out time, elapsed time, job, and description.
    The job column can be turned off by the user"""

    # write the header row
    file.write(f'date,in,out,elapsed,{'job,' if job_column else ''}description\n')
    for seg in data:
        date = seg.inTime.date()
        in_time = f'{seg.inTime.strftime('%-I:%M:%S%p%z')}'
        out_time = f'{seg.outTime.strftime('%-I:%M:%S%p%z')}'
        elapsed = f'{timedelta_HH_mm_ss(seg.elapsed)}'
        job = seg.job
        description = f'"{seg.description}"'
        file.write(f'{date},{in_time},{out_time},{elapsed},{f'{job},' if job_column else ''}{description}\n')
```
